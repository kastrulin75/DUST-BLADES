# DUST & BLADES

Пошаговая браузерная RPG в стиле старых пиксельных игр, dark fantasy.

**Играть:** https://kastrulin75.github.io/DUST-BLADES/

## Об игре

- Регистрация и вход — прогресс героя хранится в браузере (localStorage).
- Три волны врагов на выбор: скелеты, призраки, рыцари смерти и три уровня сложности.
- Атака, ярость и «Вихрь клинков», защита, зелья, комбо и критические удары.
- Торговец: улучшения силы, брони, здоровья и зелья.
- Таблица рекордов, уровни и опыт.

## Управление

| Клавиша | Действие |
|---|---|
| `Space` / `1` | Атака |
| `R` / `2` | Вихрь клинков (при полной ярости) |
| `D` / `3` | Защита |
| `P` / `4` | Зелье |
| `←` `→` / `Tab` | Выбор цели |
| `S` | Торговец |
| `Esc` | Меню |

## Запуск локально

Игра — чистые HTML, CSS и JavaScript без сборки. Достаточно открыть `index.html`
или запустить любой статический сервер в папке проекта, например:

```bash
python -m http.server 8000
```

## Структура

```
index.html        — точка входа (перенаправляет во вход или меню)
sign-in/          — вход и регистрация
main-menu/        — главное меню, настройки, рекорды
game/             — экран боя
shared/           — общий код: звук, сохранения, эффекты, стили
media/            — исходные картинки, звуки и иконки
media/px/         — облегчённые копии картинок, которые использует игра
tools/            — вспомогательные скрипты
```

Картинки персонажей лежат в `media/sprites/<персонаж>/`. После их изменения
пересоберите облегчённые копии:

```bash
python tools/optimize_sprites.py
```
